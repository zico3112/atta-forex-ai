# Understanding The Game

## Konsep Asas
Trading adalah tentang memahami 3 elemen utama secara berurutan:

```
Price → Pattern → Time
```

## Breakdown 3 Elemen

### 1. Price (Harga)
Alat untuk baca price:
- **SNR** (Support & Resistance) — Aras sokongan dan rintangan
- **SND** (Supply & Demand) — Zon penawaran dan permintaan
- **Candle** — Analisa candlestick
- **Trendline** — Garisan trend

### 2. Pattern (Corak)
- **Chart Pattern** — Corak keseluruhan chart
- **Candlestick Pattern** — Corak lilin individu/kumpulan

### 3. Time (Masa)
- **Fibonacci** — Nombor dan nisbah Fibonacci untuk anggaran masa dan harga
- **ETA** (Estimate Time Analysis) — Anggaran masa pergerakan mengikut timeframe

## Entry Framework
Untuk entry, perlu ada:
- **PB** (Pullback) atau **Breakout**
- **Confirmation** — Pengesahan setup
- **Risk Reward** — Nisbah risiko dan pulangan mesti berbaloi

## Jenis Market
1. **Trend** — Market bergerak satu arah
2. **Sideway** — Market bergerak mendatar (range)

## Rule Asas
> Baca Price dahulu → Kenal Pattern → Guna Time untuk estimate → Baru entry
