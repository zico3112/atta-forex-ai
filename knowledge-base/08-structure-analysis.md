# Structure Analysis

## Asas Market Structure

### Uptrend
- **HH** (Higher High) + **HL** (Higher Low)
- Setiap puncak lebih tinggi dari puncak sebelum
- Setiap lembah lebih tinggi dari lembah sebelum

### Downtrend
- **LH** (Lower High) + **LL** (Lower Low)
- Setiap puncak lebih rendah dari puncak sebelum
- Setiap lembah lebih rendah dari lembah sebelum

### Reversal Signal
- Dari uptrend ke downtrend: HH → LH → LL terbentuk
- Dari downtrend ke uptrend: LL → HL → HH terbentuk

## Rule Paling Penting
> **"Structure tua MESTI lebih daripada structure corrective"**
> 
> Bermakna: Pergerakan trend (impulse) mesti lebih besar/panjang dari pergerakan corrective (pullback)
> Jika corrective lebih besar — trend dah invalid, kemungkinan reversal

## Market Cycle

### Completed Cycle
- Satu kitaran penuh = **2 cycle**
- Diagram: X → A (puncak) → B (lembah) = Completed Cycle
- Bila cycle complete, tunggu setup baru

### 2 Cycle Chart
- Selepas 2 cycle selesai, market biasanya akan start satu fasa baru
- Ini membantu identify bila nak exit atau skip trade

## Structure Number Sequence (SNS)
Hatta menggunakan sistem nombor unik untuk kira struktur:
- Formula asas: +4 untuk setiap step

| Jenis Market | Sequence Nombor |
|-------------|-----------------|
| **Trend** | 5, 9, 13, 17, 21, 25, 29, 33, 37... |
| **Corrective** | 3, 7, 11, 15, 19, 23, 27, 31... |
| **Sideway** | 31, 35, 39... |

### Cara Guna SNS
- Kira bilangan candle dalam struktur
- Compare dengan sequence number
- Ini membantu estimate berapa lama lagi struktur akan berlaku

## Reversal Setup (Non-Confirm)

### Pattern XABCD
- **X** = titik permulaan
- **A** = puncak/lembah pertama
- **B** = neckline (sokongan/rintangan)
- **C** = puncak/lembah semula (lebih rendah dari A untuk sell)
- **D** = entry zone

### Sell Setup (Non-Confirm) — Front/End
- Tunggu X → A → B (neckline) → C terbentuk
- **Xvalidation** = re-test neckline = entry dengan risiko lebih rendah
- **Entry risk** = entry lebih awal dengan risiko lebih tinggi
- **Confirm** = tunggu candle close untuk pengesahan

### Buy Setup (Non-Confirm) — Front/End
- Sama tapi terbalik (untuk buy)
